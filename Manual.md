# AI Chatbot Manual (Butt Networks)

## Overview
This project is a Machine Learning-based chatbot built using:
- Logistic Regression (sklearn)
- TF-IDF Vectorizer
- Rule-based keyword enhancement
- CSV-based training dataset

It is designed to understand user messages and return the most relevant response from predefined intents.

---

## Features

- Intent classification using ML
- Multi-intent detection support
- Keyword-based fallback system
- Confidence scoring
- Handles mixed queries (e.g. "pricing and services")
- Easy dataset expansion via CSV
- Fast lightweight model
